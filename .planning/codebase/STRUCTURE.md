## Directory Purposes

**`src/routes/`:**
- Purpose: TanStack Router file-based routes (SSR + client).
- Contains: `__root.tsx` (layout/head), `index.tsx` (single page).
- Key files: `src/routes/__root.tsx`, `src/routes/index.tsx`.
- Note: Any new file here regenerates `src/routeTree.gen.ts`; the app is currently a single-route SPA (no client-side routing beyond `/`).

**`src/components/desk/`:**
- Purpose: The application screen and its settings surface.
- Contains: Two large components — `DeskApp` and `SettingsPanel`.
- Key files: `src/components/desk/app.tsx` (824 lines), `src/components/desk/settings.tsx` (564 lines).

**`src/components/ui/`:**
- Purpose: Shared visual primitives built on `class-variance-authority` + `cn()`.
- Contains: `button.tsx` (`buttonVariants`, `asChild` via Radix Slot), `input.tsx`, `badge.tsx`.
- Key files: `src/components/ui/button.tsx`.

**`src/lib/`:**
- Purpose: Browser-safe helpers and the API client. Anything here may be imported by components.
- Contains: `desk/client.ts`, preview bridge modules, formatting utilities, error component.
- Key files: `src/lib/desk/client.ts`, `src/lib/utils.ts`.
- Constraint: No `node:*` imports allowed in this tree (it ships to the browser).

**`src/server/`:**
- Purpose: The local controller. Node-only. Mounted at `/api` by `vite.config.ts`.
- Contains: Transport, routing, runtime supervision, OpenCode adapter, normalization, security, persistence, and their tests.
- Key files: `src/server/http.ts`, `src/server/api.ts`, `src/server/runtime.ts`, `src/server/opencode-client.ts`.
- Constraint: Never import these from `src/components/` or `src/lib/`; they pull in `node:fs`/`node:child_process`.

**`server/`:**
- Purpose: Nitro/h3 middleware for deployed builds only (auto-registered because `vite.config.ts` sets `serverDir: "./server"`).
- Contains: `middleware/grok-pwa.ts`, ambient type for `virtual:grok-og-identity`.
- Key files: `server/middleware/grok-pwa.ts`.

**`scripts/`:**
- Purpose: Everything around the app — env injection, Vite plugins, installers, QA capture, migration/auth scaffolding.
- Contains: Plain `.mjs` modules, each with a co-located `.test.mjs` where tested.
- Key files: `scripts/with-app-env.mjs`, `scripts/app-env-plugin.mjs`, `scripts/grok-pwa-shared.mjs`, `scripts/grok-pwa-plugin.mjs`, `scripts/migration-plan.mjs`, `scripts/link-cli.mjs`.
- Note: Several scripts (`migrate.mjs`, `migration-plan.mjs`, `sign-out-plan.mjs`, `check-auth-invariant.mjs`, `browser-smoke*.mjs`, `brand-check.mjs`, `preview-thumbnail.mjs`, `pack-selfhost.mjs`) come from the app-builder template and are not part of the Paddy runtime path.

**`public/`:**
- Purpose: Vite static root; copied verbatim to output.
- Contains: `favicon.svg`, `paddy-icon*.png`, `og.jpg`, `install.sh`/`install.ps1` mirrors, and `paddy-sprites/` (idle 1–5, drink 1–7, jig 1–9, toss 1–8).
- Key files: `public/paddy-sprites/` (referenced by `src/components/paddy-mascot.tsx`).

**`docs/`:**
- Purpose: Static GitHub Pages landing page and installer copies.
- Contains: `index.html`, `install.sh`, `install.ps1`, `.nojekyll`.

## Key File Locations

**Entry Points:**
- `bin/paddy.mjs`: CLI; runs `npm run dev -- --host 127.0.0.1 --port 8080`.
- `vite.config.ts`: Dev/preview server, mounts `/api`, adds Nitro on build.
- `src/router.tsx`: TanStack Start router factory.
- `src/routes/__root.tsx`: HTML document shell.
- `server/middleware/grok-pwa.ts`: Production PWA/OG middleware.

**Configuration:**
- `package.json`: Scripts (`dev`, `build`, `test`, `typecheck`, `lint`, `format`), deps, `bin.paddy`.
- `tsconfig.json`: `strict`, `allowImportingTsExtensions`, `@/* → ./src/*`; includes `src` + `server`.
- `vite.config.ts`: Ports 8080/8081, host binding guard, plugin order.
- `eslint.config.mjs`: Flat config; ignores `src/routeTree.gen.ts`, `dist`, `.vercel`, `.nitro`.
- `config.json` + `.grok/app-env.json`: Platform/app metadata for `scripts/app-env-plugin.mjs`.
- `Dockerfile`, `docker-compose.yml`: Container runtime and state volume (`/state`).
- `.env*` files: only `selfhost.env.example` is present (template, no secrets read).

**Core Logic:**
- `src/server/api.ts`: Every `/api` route lives in `handleApi`.
- `src/server/runtime.ts`: Connection lifecycle and event fan-out.
- `src/server/opencode-client.ts`: Every OpenCode HTTP endpoint used by the app.
- `src/server/normalize.ts`: Wire-format translation.
- `src/server/security.ts`: Auth, origin, allowlist, redaction.
- `src/components/desk/app.tsx`: UI state machine and layout.
- `src/lib/desk/client.ts`: Browser-side contract with `/api`.

**Testing:**
- `src/server/*.test.ts`: `security.test.ts`, `opencode-client.test.ts`, `api.test.ts`, `normalize.test.ts`, `state.test.ts`.
- `src/components/autonomous-drink.test.ts`: Injected-clock scheduler tests.
- `scripts/*.test.mjs`: Node test suites for installers, PWA shared logic, migration plan, preview, link-cli, etc.
- `install.sh.test.mjs` (repo root): Installer smoke test, run first by `npm test`.

**Styling:**
- `src/styles.css`: `@theme` design tokens, `[data-theme="light"]` overrides, keyframes (`rise-in`, `pulse-live`, `shimmer-text`, `paddy-idle--*`).

## Naming Conventions

**Files:**
- React components: **kebab-case** filenames with PascalCase exports — `src/components/paddy-mascot.tsx` → `PaddyMascot`, `src/components/desk/app.tsx` → `DeskApp`.
- Hooks: `use-*.ts` — `src/components/use-autonomous-drink.ts` → `useAutonomousDrink`.
- Server modules: single lowercase word, no suffix — `api.ts`, `state.ts`, `runtime.ts`, `security.ts`, `normalize.ts`, `http.ts`.
- Browser-safe lib modules: kebab-case — `preview-host-bridge.ts`, `error-component.tsx`.
- Tests: co-located, `<module>.test.ts` (server/components) or `<module>.test.mjs` (scripts).
- Generated: `src/routeTree.gen.ts` — never hand-edit.
- Special route file: `__root.tsx` (TanStack convention).

**Directories:**
- Feature folders lowercase — `desk/`, `ui/`, `og/`, `middleware/`, `routes/`, `server/`.

**Exports:**
- Named exports only (`export function DeskApp`, `export const api`, `export class ControllerRuntime`). No default exports except the Nitro middleware (`export default async function grokPwaMiddleware`).
- Types exported alongside their implementation (`export type GuiEvent`, `export type ConnectionStatus`).

**Identifiers:**
- React state setters: `[thing, setThing]`; refs end in `Ref`/`bottom`/`composer`.
- Server runtime methods: verbs — `connect`, `attach`, `probe`, `persist`, `requireClient`, `subscribe`.
- API client methods mirror the HTTP intent — `api.openSession`, `api.patchConfig`, `api.mcpAction`.
- Event discriminants: lowercase dotted/kebab (`"text-delta"`, `"permission-cleared"`, `"session-deleted"`).

## Where to Add New Code

**New `/api` endpoint (e.g. a new OpenCode capability):**
1. Add the OpenCode call in `src/server/opencode-client.ts` (only place that knows the path).
2. Add a route branch in `handleApi` (`src/server/api.ts:23-60`) plus a handler function below it.
3. Add the method to `api` in `src/lib/desk/client.ts:118-172` and, if it returns new shapes, a type near the top of that file.
4. If the result is streamed, add the event variant to `GuiEvent` (`src/server/normalize.ts:54-65`), map it in `normalizeEvent`, add the same variant to `DeskEvent` (`src/lib/desk/client.ts:81-93`), and handle it in `applyEvent` (`src/components/desk/app.tsx:55-116`).
5. Add a test in `src/server/api.test.ts` (see `makeRuntime`/fake-fetch pattern there) and register any **new** test file in the `test` script in `package.json` — the runner lists files explicitly.

**New UI screen or panel:**
- Primary code: `src/components/desk/` for full-screen surfaces (follow `SettingsPanel`), or `src/components/` for reusable pieces.
- Reuse primitives from `src/components/ui/` (`Button`, `Input`, `Badge`) and `cn()` from `src/lib/utils.ts`; use tokens `bg-bg`, `bg-surface`, `bg-elevated`, `text-fg`, `text-muted`, `text-subtle`, `border-border`, `text-accent`, `text-ok`, `text-warn`, `text-danger`.
- Add state via `api.*` calls from `src/lib/desk/client.ts`; never `fetch("/api/...")` directly.

**New route:**
- Create `src/routes/<name>.tsx` with `createFileRoute("/<name>")`; the router plugin regenerates `src/routeTree.gen.ts` on dev/build. Do not edit the generated file.

**New shared helper (browser-safe):**
- `src/lib/<name>.ts`. If it is pure and worth testing, co-locate `<name>.test.ts` and add it to the `test` script.

**New server module:**
- `src/server/<name>.ts`, imported with an explicit `.ts` extension (the repo uses `allowImportingTsExtensions` — e.g. `import { handleApi } from "./api.ts"`).

**New build/dev script:**
- `scripts/<name>.mjs` (plain ESM, no TypeScript), with `scripts/<name>.test.mjs` if testable. Wire it into `package.json` scripts only if it belongs to the normal dev/build flow.

**New animation:**
- Add frames to `public/paddy-sprites/<name>-N.png`, extend `TIMELINES` in `src/components/paddy-mascot.tsx`, and flip the flag in `src/components/paddy-animations.ts`.

**New theme token:**
- Add to `@theme` and the `[data-theme="light"]` block in `src/styles.css`; reference it as a Tailwind class (`bg-*`, `text-*`, `border-*`).

## Special Directories

**`node_modules/`:**
- Purpose: Installed dependencies.
- Generated: Yes.
- Committed: No (gitignored). Do not search or edit.

**`.vercel/`, `dist/`, `.output/`, `.nitro/`:**
- Purpose: Build/deploy output and Vercel link metadata.
- Generated: Yes.
- Committed: No. Excluded from ESLint and out of scope for analysis.

**`.planning/codebase/`:**
- Purpose: GSD codebase maps consumed by `/gsd-plan-phase` and `/gsd-execute-phase`.
- Generated: Yes (by mapper agents).
- Committed: Yes (project planning state).

**`.grok/`:**
- Purpose: Platform app metadata (`app-env.json`) used by `scripts/app-env-plugin.mjs` and PWA/OG tooling.
- Generated: No.
- Committed: Yes.

**`public/paddy-sprites/`:**
- Purpose: Frame-by-frame mascot artwork referenced by hardcoded filenames in `src/components/paddy-mascot.tsx`.
- Generated: No (hand-supplied art).
- Committed: Yes. Renaming files breaks the animation timelines.
