| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Spoofing | authorizePeer locality (security.ts) | high | mitigate | Anonymous trust requires loopback bindHost AND loopback Host header; socket peer alone never grants trust |
| T-01-02 | Spoofing | originAllowed (security.ts) | high | mitigate | Validate Origin then Referer as same-origin; reject cross-origin with 403 before auth |
| T-01-03 | Information disclosure | token comparison (security.ts, http.ts) | medium | mitigate | Use node:crypto.timingSafeEqual with length check instead of string inequality |
