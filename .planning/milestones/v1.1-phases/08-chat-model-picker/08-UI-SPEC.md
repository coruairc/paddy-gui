# Phase 8 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Sources of this contract.** Interaction behaviour, persistence semantics, grouping/filtering rules and every
"what the picker shows" decision are pre-populated from `08-CONTEXT.md` (locked) and `08-RESEARCH.md` (live
OpenCode v2.3.2 wire facts). Tokens and component patterns are read from `src/styles.css`,
`src/components/desk/app.tsx`, `src/components/desk/settings.tsx` and `src/components/ui/*`. Only visual
defaults not fixed by those sources are declared here.

**Autonomous run — auto-selected values recorded (no user present).** Each is a conservative choice consistent
with the existing desk, and each is reversible by editing this file before planning:

1. Trigger styling reuses `Button variant="ghost" size="sm"` so it matches the existing header chrome instead of
   introducing a new control style.
2. Popup geometry: `w-[min(24rem,calc(100vw-1.5rem))]`, `max-h-[min(26rem,60dvh)]`, anchored below-right of the
   trigger; no flip logic (the trigger sits in a top-of-viewport 56px header).
3. Provider group labels: explicit brand map for the 10 providers observed live (`openai` → OpenAI,
   `github-copilot` → GitHub Copilot, `opencode-go` → OpenCode Go, …) with title-case fallback for unknown ids;
   the raw `providerID` remains the key.
4. Metadata line format `status · context · release` using the existing `formatTokens` (k/M) and `MMM YYYY`.
5. Deprecated/non-active de-emphasis uses `text-muted` + badges, never `opacity-*` (opacity fails 4.5:1).
6. Persistence-failure note lives in the composer hint slot in `text-warn`; the global error bar is not used
   (its Reconnect affordance would be misleading for a model-save failure).
7. Stale persisted model is signalled by a `text-warn` icon on the trigger + an `sr-only` description + a banner
   row inside the popup.
8. `Tab` closes the popup and returns focus to the trigger (deterministic; avoids focusing a removed node).
9. No trigger or option is ever `disabled` this phase (offline opens an explanatory panel instead).
10. No popup entrance animation; only 150ms colour transitions, covered by the existing reduced-motion override.
11. The search field is a bare `<input>` inside the shell; the visible focus ring is on the popup shell
    (`focus-within:ring-2 ring-accent/40`).
12. Stable `data-*` hooks are added for the existing Playwright smoke script / Phase 10 verification.

- **Options use `min-h-11` (44px)** — touch target for the primary list interaction.

- **Icon glyph sizes** (`size-3` 12px, `size-3.5` 14px, `size-4` 16px) follow lucide's 2px grid and are element dimensions, not spacing tokens.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-bg` (#0a0a0b dark / #f6f6f4 light) | Header strip the trigger sits in; page behind the popup |
| Secondary (30%) | `--color-elevated` (#18181b / #efefec); `--color-surface` (#111113 / #ffffff) | Popup shell + sticky group headers (`bg-elevated`); hovered and keyboard-active row fill (`bg-surface`) |
| Accent (10%) | `--color-accent` (#7d9e72 dark / #18181b light) | Reserved list below |
| Warn | `--color-warn` (#c4a574 / #9a6b2f) | Stale-model icon, persistence-failure note, Alpha/Beta badges |
| Danger | `--color-danger` (#c07a72 / #a33b34) | Load-failure icon and detail text only — no destructive actions exist this phase |

Accent reserved for, exhaustively:
1. the `Check` icon marking the effective (selected) model — `text-accent`, `aria-hidden`;
2. the 2px left bar of the keyboard-active option (`border-l-2 border-accent`);
3. focus rings — the trigger (`Button`'s `focus-visible:ring-2 ring-accent/40`) and the popup shell (`focus-within:ring-2 ring-accent/40`).

Accent is **not** used for: row hover fill, the selected row background, the "Default" badge, group headers,
the search icon, the Retry/Clear-filter buttons, or the popup border.

**Text contrast rule (non-negotiable).** All picker text uses `text-fg` or `text-muted`. `text-subtle` is
never used for text in this phase: on `bg-elevated` in dark theme it measures ≈2.7:1. `text-muted` measures
≈4.9:1 on elevated dark and ≈7:1 on light — both pass 4.5:1 at 11px. De-emphasis (deprecated rows) is achieved
with `text-muted` + a "Deprecated" badge, never `opacity-*` (opacity drops the effective contrast below 4.5:1).
Placeholder text uses `placeholder:text-muted`, not the `Input` primitive's `text-subtle`.

## Component Specs

All classes below are the contract. Any deviation must preserve the stated token, size, contrast and ARIA.

### 8.1 Header trigger

- Placement: first child of the header's right-hand cluster in `app.tsx` (the `flex items-center gap-2` div
  holding the Live indicator), so order is **`[model trigger] · [Live/Offline] · [Retry/Rename/Archive]`** —
  immediately left of the Live indicator, as decided.
- Rendered whenever a project is selected (no session required), including while Settings is open (the `model`
  state is shared with Settings' Providers control). **Absent** when no project is selected.
- Markup: `<div className="relative" data-model-picker>` wrapping
  `<Button type="button" variant="ghost" size="sm" aria-haspopup="listbox" aria-expanded={open} aria-controls={open ? "model-picker-popup" : undefined} aria-label={...}>`.
- Visual: `h-8`, `text-xs`, `text-muted`, `hover:text-fg hover:bg-elevated` (the `ghost` variant's own states),
  `max-w-[14rem]`, content `flex items-center gap-1`. Open/active state: `bg-elevated text-fg`.
- Label: `truncate max-w-[10rem]`; at `max-sm` `max-w-[7rem]`. Never hidden at narrow widths — the Live/Offline
  **text** may collapse to its dot below `sm`, the model name must not.
- Trailing `ChevronDown` `size-3.5`, `transition-transform duration-150`, `rotate-180` while open, `aria-hidden`.
- Stale-model state: prepend `AlertCircle size-3 text-warn aria-hidden` and set
  `aria-describedby="model-picker-stale"` pointing at the `sr-only` note.
- If the popup is open and the effective model changes by SSE, the label updates in place with no flash, no
  toast and no focus change.
- **Not disabled** in any state. Offline, loading and error states are surfaced by the popup, not by a greyed
  trigger.

### 8.2 Popup shell

- `absolute right-0 top-full mt-2 z-50 w-[min(24rem,calc(100vw-1.5rem))] overflow-hidden rounded-xl border border-border bg-elevated shadow-[var(--shadow-border-hover)]`.
- `focus-within:ring-2 focus-within:ring-accent/40` — this is the visible focus indicator while focus is inside
  (the filter input itself renders `focus:outline-none`).
- No entrance animation. `id="model-picker-popup"`. Renders one of: **list**, **loading**, **offline**,
  **error**, **empty**. It is never a blank panel.
- Rendered inline in the header's stacking context (no portal). The header does not clip overflow, and `z-50`
  paints above the thread and inspector.
- No `role="dialog"` — focus is not trapped and `Tab` closes the popup.

### 8.3 Search row (list state only)

- `flex items-center gap-2 border-b border-border px-3 py-2`.
- `Search` icon `size-3.5 shrink-0 text-muted aria-hidden`.
- `<input role="combobox" aria-expanded="true" aria-controls="model-picker-listbox" aria-activedescendant={activeOptionId || undefined} aria-autocomplete="list" aria-label="Filter models" placeholder="Filter models" autoComplete="off" spellCheck={false}>`
  with `h-6 min-w-0 flex-1 bg-transparent text-sm text-fg placeholder:text-muted focus:outline-none`.
- Autofocused on open, caret at end, query empty. Typing filters live (substring over `name`, `id`,
  `providerID`, case-insensitive — the Settings precedent).
- `sr-only` result announcer: `<span role="status" aria-live="polite" className="sr-only">` containing
  `{n} models` / `1 model` / `No models match`, updated on every filter change and on load completion.

### 8.4 Group header (list state)

- `sticky top-0 z-10 flex items-center justify-between border-b border-border bg-elevated px-3 py-2`.
- Label: `truncate text-[11px] font-medium tracking-wide text-muted uppercase`, humanized provider name
  (`humanizeProviderID`: explicit brand map for the 10 live providers, title-case fallback), with
  `id="model-group-{providerSlug}"` for `aria-labelledby`.
- Count: `text-[11px] text-muted tabular-nums`, `aria-hidden`.
- Groups sorted alphabetically by the humanized label; models inside a group sorted alphabetically by `name`.
  No MRU ordering this phase.

### 8.5 Option row

- `<div role="option" tabIndex={-1} id="model-option-{slug}" aria-selected={key === effectiveKey}>`.
- Base: `flex min-h-11 cursor-pointer flex-col justify-center gap-1 border-l-2 border-transparent px-3 py-2 transition-colors`.
- Line 1: `flex min-w-0 items-center gap-2` → name `min-w-0 flex-1 truncate text-sm leading-normal` in
  `text-fg` (`text-muted` when status is `deprecated`), then the `Default` badge, then the selected `Check`
  (`size-3.5 text-accent`, `aria-hidden`).
- Line 2: `flex min-w-0 items-center gap-1 truncate text-[11px] leading-snug text-muted`.
  Segments joined by ` · ` (U+00B7 with spaces): **status · context · release**.
  - `active` renders as plain lowercase text; `alpha`/`beta` render as `Badge variant="warn"`,
    `deprecated` as `Badge variant="default"`.
  - context: `formatTokens(context)` + ` context` (e.g. `1.0M context`); released:
    `toLocaleDateString(undefined, { month: "short", year: "numeric" })` (e.g. `Nov 2026`).
  - Missing/zero values render `context unknown` / `release unknown`; a missing name falls back to `id`.
- Hover: `bg-surface` (CSS only — hover does not move the keyboard-active option). Keyboard-active
  (`data-active="true"`): `bg-surface border-accent`. Selected: the `Check` icon. Selected + active shows both.
- `<300px`-wide popups keep both lines; the metadata line truncates with an ellipsis.
- Deprecated rows stay selectable (every catalog entry is selectable this phase; an unusable provider fails
  honestly at prompt time).
- No cost, capability or variant UI (MODEL-04 deferred).

### 8.6 State panels

Common shell: `flex flex-col items-center gap-2 px-4 py-8 text-center`. Heading `text-xs font-medium text-fg`
(12/500). Body `text-[11px] text-muted` (11/400), `max-w-[34ch]`.

| State | Visual | Content |
|-------|--------|---------|
| Loading | `HelixMark spinning className="size-6"` + `Loading models…` | Trigger keeps its last known label |
| Offline | `WifiOff size-4 text-muted aria-hidden` + heading + body | No filter input; `role="status"` on the panel |
| Error | `AlertTriangle size-4 text-danger aria-hidden` + heading + detail (`line-clamp-2 text-[11px] text-muted`) + `Button variant="outline" size="sm"` `Retry` | `Retry` re-fetches; while in flight it reads `Retrying…` and is disabled |
| Empty catalog | `Boxes size-4 text-muted aria-hidden` + heading + body | Connected, `models.length === 0` |
| No match | `SearchX size-4 text-muted aria-hidden` + heading + `Button variant="outline" size="sm"` `Clear filter` | Clearing resets the query and refocuses the input |
| Stale banner | `flex items-start gap-2 border-b border-border px-3 py-2 text-[11px] text-muted` with `AlertCircle size-3.5 text-warn` | Rendered above the list; same text as the `sr-only` note |

### 8.7 Keyboard map

| Key | Trigger focused (closed) | Popup open (focus in filter input) |
|-----|--------------------------|------------------------------------|
| Enter / Space | Open; focus input; active = effective model if present, else first option | Select the active option |
| ArrowDown | Open; focus input; active = effective model if present, else first | Move active down one (clamped, no wrap) |
| ArrowUp | Open; focus input; active = effective model if present, else last | Move active up one (clamped, no wrap) |
| Home / End | — | First / last option, crossing group boundaries |
| Escape | — | Close; return focus to the trigger |
| Tab / Shift+Tab | — | Close; return focus to the trigger (no focus loss, no trap) |
| PageUp / PageDown | — | Not bound this phase |

Behavioural rules:
- Arrow navigation moves across the **flattened filtered list**, not one group at a time, and calls
  `scrollIntoView({ block: "nearest" })` on the newly active option.
- `aria-activedescendant` is set on the **filter input** and stays in sync; it is removed when no option is
  active (empty list).
- Selecting with the pointer does not require the row to be keyboard-active first.
- Selection closes the popup and moves focus to the composer textarea; if the composer is not mounted (Settings
  open), focus returns to the trigger.
- Outside pointer-down closes the popup without moving focus. Re-clicking the trigger toggles closed and focuses
  the trigger.

### 8.8 ARIA contract (verbatim)

| Element | Required attributes |
|---------|---------------------|
| Trigger | `<button type="button" aria-haspopup="listbox" aria-expanded={open} aria-controls={open ? "model-picker-popup" : undefined} aria-label={\`Model: ${label}. Open model picker.\`}>` |
| Filter input | `role="combobox"`, `aria-expanded="true"`, `aria-controls="model-picker-listbox"`, `aria-activedescendant={activeOptionId}`, `aria-autocomplete="list"`, `aria-label="Filter models"` |
| Listbox | `role="listbox" id="model-picker-listbox" aria-label="Models"` |
| Group | `role="group" aria-labelledby="model-group-{providerSlug}"` (div, inside the listbox) |
| Option | `role="option" id="model-option-{slug}" aria-selected={key === effectiveKey} tabIndex={-1}` |
| Announcer | `role="status" aria-live="polite" class="sr-only"` |
| Stale note | `id="model-picker-stale"` + `sr-only`; referenced by the trigger's `aria-describedby` |

`{slug}` = key with every character outside `[A-Za-z0-9_-]` replaced by `_` (model ids may contain `/`).
Element ids must be unique even when two entries share a `modelID` — the key is `providerID/id`, so they are.

### 8.9 Focus lifecycle

| Event | Focus result |
|-------|--------------|
| Open (click / Enter / Space / Arrow) | Filter input (caret at end) |
| Escape, Tab, Shift+Tab | Trigger |
| Select an option | Composer textarea, else trigger |
| Outside pointer-down | Unchanged (no focus steal) |
| Trigger clicked while open | Trigger |
| SSE reconciliation while open | Unchanged (no focus move, popup stays open) |

### 8.10 Notes outside the popup

- **Persistence failure** (`api.settings({ deskModel })` rejects): the pick still applies for the current turn;
  render `Model saved for this turn only — it will not survive a reload.` in the composer hint slot —
  `mx-auto mt-2 max-w-2xl px-2 text-[11px] text-warn` — above the existing `Enter to send · …` line. Cleared on
  the next successful model write or on reload. The desk's global `error` bar is **not** used.
- **Persisted key is not in the catalog**: effective model = OpenCode's `default`; trigger shows that name +
  `AlertCircle text-warn`; the popup carries the stale banner. Nothing is written to state until the user picks
  or sends.
- **Wire key reminder for the executor:** the settings write is `api.settings({ deskModel: key })` — the key
  Phase 7 actually landed (`settings.tsx:313`). `08-RESEARCH.md`'s older `{ model: key }` sketch is stale.

### 8.11 Responsive and motion

- The popup is width-clamped (`min(24rem, 100vw - 1.5rem)`) so it fits at 320px; height is capped at
  `min(26rem, 60dvh)` with internal scrolling (`scrollbar-thin`, `overscroll-contain`).
- Header order at narrow widths: trigger (name visible, truncated) then the Live dot; Retry/Rename/Archive stay
  hidden below `sm` as today.
- No new keyframes. Only `transition-colors` / `transition-transform` at 150ms, which the existing
  `@media (prefers-reduced-motion: reduce)` block in `src/styles.css` already neutralises.

### 8.12 Non-visual hooks (for the existing Playwright smoke script / Phase 10)

`data-model-picker` (trigger wrapper), `data-model-picker-trigger`, `data-model-picker-state="list|loading|offline|error|empty|no-match"`, `data-model-option="{key}"`, `data-active="true|false"`. These are additive and carry no styling.
