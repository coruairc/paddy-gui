<objective>
Close the trust loop: the header reconciles against OpenCode's own `session.model.selected` events and against the session's stored model on resume, and a project switch can no longer overwrite the persisted desk default.

Purpose: MODEL-02's "never drifts from what actually runs" is this plan. After it lands, an external model switch (OpenCode TUI, another tab) updates every open desk header through the existing SSE fan-out, resume shows the session's real model, and the only writer of the desk default is the picker.

Output: one additive event variant end-to-end, the resume projection, the reducer branch, and the `chooseProject` guard removal.

Decision trace (08-CONTEXT.md §Implementation Decisions):
- "Reconciliation & Resume": one additive `GuiEvent`/`DeskEvent` variant `{ type: "model-selected", sessionId, model }` normalized from `session.model.selected`, ignoring `previous`; fan-out is the existing runtime loop.
- "Reconciliation & Resume": only the active session's event moves the header, via an explicit `event.sessionId === sessionRef.current` check before the generic session gate.
- "Reconciliation & Resume": resume seeds from `Session.Info.model` surfaced as optional `SessionSummary.model`; the desk default applies only when the session has no model.
- "Reconciliation & Resume": `variant` is ignored everywhere, including the server-normalized `"default"`.
- Deferred from Phase 7 and explicitly scoped here: the `chooseProject` config re-read that clobbers the desk model (research Pitfall 10).
</objective>
