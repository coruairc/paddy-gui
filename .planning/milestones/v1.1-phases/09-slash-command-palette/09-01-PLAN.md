## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OpenCode → controller | Command catalog and error bodies are untrusted; only name/description cross |
| browser → controller | A command name/args pair is browser input dispatched to OpenCode |
| controller → browser | Error messages are rendered in-thread |
