# v1.0 Milestone Integration Audit

## Summary

All six phases are present and their primary code paths are wired together. Automated gates pass (`npm run lint`, `npm run typecheck`, `npm test` (71/71), `npm run build`). No cross-phase connection is absent to the point of breaking an E2E user flow, so there are no BLOCKERs. The remaining items are documentation/count drift and leftover app-builder scaffolding, classified as tech debt.

## Wiring Summary

**Connected (verified end-to-end):**
- Phase 1 `security.ts` (`authorizePeer`, `isLoopbackHost`, `originAllowed`, `validateWorkspacePath`, `redactSecrets`) → `http.ts` → `vite.config.ts` middleware (dev + preview)
- Phase 1 auth → Phase 2 loop: `/api/*` routes enforce origin + token before `handleApi`
- Phase 2 `messages.ts` reducers → `app.tsx` (`appendDelta`, `mergeMessage`, `upsertActivity`, `upsertSession`)
- Phase 2 password semantics → `settings.tsx` (`hasConnectionPassword`, clear-password button) → `api.ts` (`updateSettings`)
- Phase 2 runtime lifecycle → `vite.config.ts` signal handlers (`SIGINT/SIGTERM/SIGHUP/beforeExit` → `runtime.disconnect()`)
- Phase 2 permission flow → `api.ts` (`replyPermission`) → `opencode-client.ts`
- Phase 3 cleanup → Phase 4 gates: lint/typecheck/test all green
- Phase 4 CI → `.github/workflows/ci.yml` (lint, typecheck, test on push/PR)
- Phase 5 state path → `state.ts` (`OPENCODE_WEB_HOME`) → Dockerfile/`docker-compose.yml` (`/state`)
- Phase 5 installers → `bin/paddy.mjs` / `link-cli.mjs` / `install.sh` / `install.ps1`
- Phase 6 → `ACCEPTANCE.md` (date, environment, steps, results)

**Orphaned / leftover (non-blocking):**

## Detailed Findings

### Warnings (tech debt)

1. **Leftover app-builder scaffolding** — `vite.config.ts` still mounts `appEnvPlugin()` and npm scripts still route through `scripts/with-app-env.mjs`; `.grok/app-env.json`, `src/lib/env.server.ts`, and `src/lib/og/` remain. Phase 3 CLN-01 is only partially satisfied. Non-blocking.
2. **Test-count documentation drift** — `ACCEPTANCE.md` and phase verification reports state 91 tests; `npm test` currently reports 71 (after removal of the stale root `install.sh.test.mjs` and `check-auth-invariant` test in Phase 4). The suite is green; only the documented count is stale.
3. **Lint warning count drift** — `ACCEPTANCE.md` states 6 warnings; current `npm run lint` reports 5 warnings (0 errors).
4. **State-directory variable duality** — `state.ts` reads `OPENCODE_WEB_HOME`, while `bin/paddy.mjs` accepts `PADDY_HOME` and translates it. README documents both. Functional, but the "single state-directory variable" contract is not strictly met.
5. **MVP goal format** — Phases 1 and 2 have `mode: mvp` but goals are capability statements, not User Stories, so MVP-mode User Flow Coverage sections were not generated. Recorded in phase verification reports.

### Blockers

None.
