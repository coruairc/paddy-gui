    4. Add killChild():
       ```
       private async killChild(): Promise<void> {
         const child = this.child;
         if (!child || child.killed) { this.child = null; return; }
         this.child = null;
         const pid = child.pid;
         const killGroup = (signal) => {
           if (pid && pid > 1) { try { this.killImpl(-pid, signal); return; } catch { /* fall through */ } }
           try { child.kill(signal); } catch { /* already gone */ }
         };
         killGroup("SIGTERM");
         const exited = await waitForExit(child, 5000, this.sleepImpl);
         if (!exited) killGroup("SIGKILL");
         await waitForExit(child, 5000, this.sleepImpl).catch(() => {});
       }
       ```
       Need a waitForExit helper that resolves true when child emits "exit", false after timeout. Use sleepImpl for polling or setTimeout. Implement with event listener + sleepImpl loop.

       ```
       this.loopAbort?.abort();

       this.client = null;
       await this.killChild();
       this.ownedPassword = "";
       this.state.ownedServerPassword = "";
       this.persist();
       return this.setStatus({ connected:false, healthy:false, startedByController:false, error: undefined });
       ```
